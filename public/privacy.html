Privacy Policy

How WyBuild handles account, GitHub, billing and technical information.

Information we receive

WyBuild receives the GitHub profile information needed to sign you in and the repository access required to perform actions you request. Billing information is processed by Flutterwave; WyBuild should not store raw card details.

How data is used

We use data to authenticate you, connect the GitHub repositories you select, enforce build limits, process Pro subscriptions, diagnose requested build failures, and keep the service secure.

Storage

Project configuration and developer-tool inputs are primarily kept in your browser. Server-side records are limited to operational data such as subscription state, build counters and signing metadata required for requested features.

Third parties

GitHub is used as the source of truth for repositories and GitHub Actions builds. Flutterwave handles payment processing. Their own privacy terms govern information they process.

Your choices

You can sign out, disconnect/revoke GitHub access from GitHub, and stop using WyBuild at any time. Contact the service operator for deletion or privacy requests.
